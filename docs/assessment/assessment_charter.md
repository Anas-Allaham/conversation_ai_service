# Assessment charter v0.1

## Claim

The module reports a **CEFR-aligned Conversational Interaction Placement** from A1 through B2. It estimates performance in spoken interaction tasks; it does not issue an official CEFR certificate or claim a complete English level.

## Population and purpose

The intended users are adolescent and adult Arabic-speaking English learners using the graduation-project tutor. The result selects an initial conversational difficulty and provides a profile for future tutoring. It is not intended for immigration, employment screening, university admission, or other high-stakes decisions.

## Assessed construct

The assessment measures task achievement, interactive communication, fluency, coherence/discourse, lexical adequacy, and intelligibility. Grammar is not independently scored. A grammar error matters only through observable communicative consequences: blocked meaning, failed task completion, or repeated clarification.

## Interpretation

The final level is the highest stage reliably demonstrated through a main response and an unprepared fixed follow-up. When their combined evidence does not clearly confirm the level, a different fixed task at that same boundary is administered before stopping. Results include the first unconfirmed level, an evidence-confidence label, a subskill profile, validity warnings, version metadata, and a disclaimer.

## Reference basis

CEFR oral-interaction descriptors provide the interpretation framework; ALTE-style language-test development principles inform task review, versioning, pilot comparison, and validation. All operational questions are original project content. No third-party question bank, sample prompt, audio, branding, or scoring claim is used.
